# Public API hard cut for the next core release

The pending Persistence 0.61.0, Metrics Stable 0.62.0 and Logging Stable 0.61.0
notes select aligned public core identities. Package versions are not bumped by
source preparation. These Rust API changes preserve valid retained ledger,
collection and checkpoint bytes. No data reset or automatic transition is needed.

## Host key and bucket setup

Parse allocation keys once, then reuse the checked value:

```rust
# fn example(runtime: &ic_memory::MemoryRuntime<ic_memory::VectorMemory>) -> Result<(), Box<dyn std::error::Error>> {
let key = ic_memory::StableKey::parse("app.rows.v1")?;
let id = runtime.memory_id(&key)?;
let memory = runtime.open_memory(&key)?;
# let _ = (id, memory);
# Ok(())
# }
```

Bucket configuration uses the standard nonzero integer type:

```rust
use std::num::NonZeroU16;
let pages = NonZeroU16::new(16).unwrap();
let config = ic_memory::MemoryManagerConfig::new(pages);
assert_eq!(config.bucket_size_pages(), 16);
```

Remove the old result handling around configuration construction. Validate
caller-supplied numeric input when creating `NonZeroU16`; persisted manager
geometry still crosses the existing corruption and mismatch checks.

## Collection lifecycle

For owning maps, sets, cells, vectors, heaps and logs, hosts explicitly choose:

- `create(memory, ...)` only for zero-page allocations. Nonempty memory refuses
  before writes; a log requires both index and data allocations to be empty.
- `load(memory)` for retained state. Empty, foreign or incompatible state refuses
  without initialization, writes or growth. Cell loading returns its typed error;
  other collections retain their panic-based corruption contract.
- `reset(memory, ...)` for deliberate replacement of any contents. A log resets
  both allocations. Drop an existing owner before obtaining its allocation lease
  for reset; memory IDs and governance claims remain committed.

There is no combined initialize-or-load entrypoint. Map/set `clear` still removes
entries from a loaded collection. Region views retain their existing explicit
zero-page `initialize`, because construction itself selects a view without IO.

Use `StableCell` for both bounded and unbounded record types. It enforces
`T::BOUND` on creation, replacement and retained loading, including exact fixed
width. Previously stored values outside their declared bounds now refuse;
host-owned repair or deliberate reset must be explicit. Valid cell envelopes and
payload representations remain compatible with the pinned upstream Cell.

## Error payloads

`LedgerCommitError::Codec` carries `LedgerDecodeError::{Wire, Key, Slot}` instead
of a string. Inspect the typed source or use `Display` for diagnostics. Runtime
open errors no longer contain a key-grammar variant, and construction errors no
longer contain invalid input bucket-size syntax. Keep handling durable layout,
policy, custody, lease and corruption failures; those boundaries are unchanged.
