# IC Persistence 0.51

## [0.51.0] - Unreleased

### IC Metrics 0.16

The stable adapter now consumes published `ic-metrics` 0.16.0 at
`c0f033a8f41c280fd0fc77b2ec934d2f2b8176ed`. Its arithmetic Rust source is
unchanged from 0.15.8; the upstream minor release retires adapter publication
from IC Metrics after the transfer to Persistence. Arithmetic remains independent
and has no production dependencies.

**Breaking:** the adapter exposes Metrics arithmetic and state-error types in
its public API. Cargo treats the 0.15 and 0.16 packages as different type
identities. Hosts using those APIs must update their direct requirement to
`ic-metrics = "0.16"` alongside this Persistence release. No source shim or
parallel arithmetic version is introduced. Adapter Rust source, V1 records,
continuity checks, allocation leases and the map format remain unchanged; no
retained-data conversion or reset is required. All three Persistence packages
retain their coordinated release identity; package versions are left to release
preparation.

### Contributor tooling

The five native development dependencies and the release-metadata/Testkit server
CLI selections adopt published IC Tooling 0.68.1 at
`c9c5ef7c44e3d0c3b23c8531a5d43c1800656c0a`. Their published Rust sources are
unchanged from 0.68.0. Tooling raises its Platform/Wire requirements; this
consumer already selects Platform 0.6.15 and leaves optional Wire support off.
The prior Tooling adoption changes its five package versions/checksums; the
Metrics adoption changes only the arithmetic package version/checksum. The
independent runtime graph remains unchanged.

Prepare the selected CLIs explicitly with `make install-release-tools
install-runtime-server`; existing admitted 0.68.1 installations can be reused.
PocketIC client/server 16.1.0, the qualified stable-structures 0.7.2 substrate,
compiler pins and the reviewed Shared snapshot remain selected. This tooling
change itself requires no library or retained-data migration.
