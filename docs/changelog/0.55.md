# IC Persistence 0.55

## [0.55.1] - Unreleased

### ➕ Added

[PR #139 — Enable coordinated publication of IC Logging Stable](https://github.com/dragginzgame/ic-persistence/pull/139)
selects all four packages in one canonical roster for version projection,
bootstrap, archive qualification, receipts and dependency-ordered upload.
Prepared/final receipts require `logging_sha256`; unknown or incomplete receipts
refuse without fallback. Resume older saved releases using their original source
and tooling. Do not rewrite old release receipts to the new roster.

and Logging reopen, and sequence/time watermarks after pruning all log rows.
Publication checks all four registry identities before effects, uploads Logging
last and reconciles a rejected or lost final response without replaying earlier
packages. Own versions, selected dependencies and runtime codecs stay unchanged.
Logging's actual initial registry publication needs an explicit maintainer action.

## [0.55.0] - 2026-10-29

### ⚠️ Breaking

Metrics Stable uses the `ICMW` discriminator and bounded IC Wire 0.7.21 native
Serde/Postcard records. The maintainer explicitly approved removing all old
Metrics data. Hosts must clear the metrics map using their old release before
adoption, or provide a known fresh governed map, and advance reset epochs. No
legacy decoder, migration engine or automatic reset is maintained. Ordinary
load/save/remove refuse unknown retained formats without replacing rows.
Memory allocation custody, the allocation ledger, namespace/name keys and
Storage's B-tree format remain unchanged; never reset unrelated memory to clear
metrics. [Upgrade guide](../../crates/ic-metrics-stable/README.md#upgrade-disposition).

The complete record limit is now 6,144 bytes, accommodating bounded Postcard
integer widths for up to 256 finite histogram bounds. The new codec error variant
preserves Wire resource-admission failures. Numeric restoration keeps Metrics'
typed errors; identity/configuration checks, monotonic checkpoints and unchanged
zero-write saves remain Persistence responsibilities. Explicit removal validates
complete envelope framing while permitting invalid numeric payloads.

### 🧹 Cleanup

Both stable adapters delegate primitive encoding, collection/traversal admission
and full-input consumption to IC Wire. Metrics uses private Serde state records
so arithmetic admission continues to return its typed errors. Logging uses its
private borrowed checkpoint schema and canonical `Log::restore`; its unpublished
format uses `ICL` plus discriminator 2. Hosts retaining earlier experimental
Logging bytes must explicitly retire them or rewrite them with their old tooling.
Logging remains unpublished and the three-package publication roster is unchanged.
No performance improvement or installed execution is implied by codec adoption.
