# IC Persistence 0.54

## [0.54.1]

### ➕ Added

The unpublished `ic-logging-stable` package owns explicit load/save/remove
checkpoints over host-opened governed Storage maps. Logging's validated snapshot
contract remains the sole admission/retention/paging engine. The adapter stores
fixed limits, epoch, oldest-first entries and both append watermarks in a bounded
V1 record. An empty retained history preserves sequence/time and exhaustion.
Identity/configuration mismatch, malformed bytes and regressing or rewritten
history refuse before mutation. Identical checkpoints perform no stable write.
Hosts retain allocation, namespace/cardinality, clocks, lifecycle and cadence.
This introduces no endpoint, timer, recorder or Metrics adapter dependency.

The root lock selects published Logging 0.17.2. Native governed-store tests,
doctests and strict Clippy pass with that graph; Rust 1.91 compiles the Wasm probe.
The independent runtime runner shares the probe's bounded native Wire protocol.
`make test-runtime-logging` qualifies original Wasm on the prepared PocketIC
16.1.0 server: query non-persistence, trapped update/upgrade rollback, successful
reopen and empty-history watermarks. The full optimized runtime matrix remains
separate qualification. Existing stable formats/APIs are unchanged.

Coordinated manifest/lock projection and interrupted-state bootstrap include all
four workspace members. Publication and archive receipts retain the existing
three-package roster; Logging Stable remains `publish = false`. Existing locked
package identities are retained; the locks add only required new identities.
The normal checkout's unrelated scaffold/tooling work remains untouched.

## [0.54.0] - 2026-10-29

### ⚠️ Breaking

Metrics Stable consumes IC Metrics 0.17.0. Hosts passing arithmetic values to the
adapter must select `ic-metrics = "0.17"`; 0.16 values have a different Rust type
identity. Upstream now includes Serde admission and native IC Wire metadata by
default. Arithmetic remains allocation-free and `no_std`; optional heap recording
remains disabled here. Metrics V1 bytes, collection formats and allocation custody
are unchanged. No persisted-data migration or reset is required.

### ⬆️ Dependencies

Adopt committed Shared Tooling 0.27.6 at
`5a72359b5be19d5221334cf2c9b3204621d3f3f6` through its canonical exporter.
The selected changes cover maintenance permission admission, single-tool freshness
checks and retained validation excerpts. Scheduled maintenance remains inactive.

Select published host tooling 0.69.9 for Build, artifact/filesystem/process helpers
and native Testkit support, plus the separately installed Build and Testkit CLIs.
Persistence uses no cached baseline snapshot recipe requiring migration for the
upstream timer-state fix. Rust selections, feature boundaries, the stable-structures
0.7.2 substrate and the independent PocketIC 16.1.0 client/server pair are retained.
Prepare the updated CLI identities explicitly before their offline admission.

### 🧹 Cleanup

Publication uses one identity guard at its existing before/after checkpoints,
retaining fresh release and tag observations and the existing refusal messages.
Installed qualification shares explicit server connection and fixture installation
setup across its entrypoints. Caller-owned server preparation, canister funding,
installation order and scenario assertions remain unchanged.
