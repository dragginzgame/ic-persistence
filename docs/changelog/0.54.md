# IC Persistence 0.54

## [0.54.1] - Unreleased

### ➕ Added

Add unpublished `ic-logging-stable` with explicit load/save/remove checkpoints
over host-opened governed Storage maps. Published Logging 0.17.2 supplies the
canonical restoration, append, retention and paging engine. Persistence owns
bounded V1 bytes and checkpoint continuity: empty or exhausted history preserves
both append watermarks; malformed bytes, changed identity/configuration, regressed
watermarks, rewritten issued rows and resurrected pruned history refuse before
mutation. Identical saves perform no stable writes. Hosts retain clocks,
allocation, identity, authorization, lifecycle and cadence.

Integrate [PR #138 — Prepare governed stable checkpoints for IC Logging](https://github.com/dragginzgame/ic-persistence/pull/138)
with the existing scaffold and release-roster work. Version projection and
interrupted bootstrap cover all four members; the existing three-package
archive/publication contract remains. The root lock selects the published Logging
dependency; existing Memory/Storage/Metrics formats and the independent runtime
graph remain unchanged. Publication stays disabled for Logging Stable.

### ⬆️ Dependencies

Select Testkit and host tooling 0.69.11 for native fixture support, Build and
artifact/filesystem/process helpers, including both separately installed CLIs.
The upstream release simplifies process execution, build/package qualification
and snapshot transfer, and preserves complete nested non-UTF-8 path diagnostics.
Existing interfaces, failure evidence and recovery boundaries remain in place;
Persistence requires no caller migration.

Keep Shared Tooling 0.27.6, Metrics 0.17.0, Rust selections, feature boundaries,
stable-structures 0.7.2 and the independent PocketIC 16.1.0 pairing unchanged.
The incoming root lock already selects host tooling 0.69.11 and Platform 0.7.5;
the independent qualification lock is unchanged. CLI installation/admission and
installed-runtime qualification retain their separate evidence.

## [0.54.0] - 2026-10-29

### ⚠️ Breaking

Metrics Stable consumes IC Metrics 0.17.0. Hosts passing arithmetic values to the
adapter must select `ic-metrics = "0.17"`; 0.16 values have a different Rust type
identity. Upstream now includes Serde admission and native IC Wire metadata by
default. Arithmetic remains allocation-free and `no_std`; optional heap recording
remains disabled here. Metrics V1 bytes, collection formats and allocation custody
are unchanged. No persisted-data migration or reset is required.

### ⬆️ Dependencies

Adopt committed Shared Tooling 0.27.6 at
`5a72359b5be19d5221334cf2c9b3204621d3f3f6` through its canonical exporter.
The selected changes cover maintenance permission admission, single-tool freshness
checks and retained validation excerpts. Scheduled maintenance remains inactive.

Select published host tooling 0.69.9 for Build, artifact/filesystem/process helpers
and native Testkit support, plus the separately installed Build and Testkit CLIs.
Persistence uses no cached baseline snapshot recipe requiring migration for the
upstream timer-state fix. Rust selections, feature boundaries, the stable-structures
0.7.2 substrate and the independent PocketIC 16.1.0 client/server pair are retained.
Prepare the updated CLI identities explicitly before their offline admission.

### 🧹 Cleanup

Publication uses one identity guard at its existing before/after checkpoints,
retaining fresh release and tag observations and the existing refusal messages.
Installed qualification shares explicit server connection and fixture installation
setup across its entrypoints. Caller-owned server preparation, canister funding,
installation order and scenario assertions remain unchanged.
