# IC Persistence 0.58

## [0.58.0] - Unreleased

### ⚠️ Breaking

The maintained catalogs select Platform 0.11.1 and IC Wire 0.10.0. The library
selects Metrics/Logging 0.21.0 and IC Tooling 0.72.0. Build editor and Testkit CLI
pins independently select 0.72.0. Logging Stable and Metrics Stable expose Wire
errors through public error enums; callers matching or constructing those values
must use Wire 0.10. Consumers exchanging Metrics values must also align Metrics
identities. This requires a coordinated minor release; package versions remain
unchanged during preparation.

Platform retires its optional `wire-schema` feature. Schema integration for
Platform Principal/Account belongs to Wire's opt-in `platform-types` feature.
Persistence selects neither integration nor Wire endpoints, so no consumer source
migration or new feature is needed. Durable ledger, Metrics and Logging bytes,
frame admission, bounds, arithmetic, logging semantics and allocation custody
remain unchanged; no data reset or retained-data migration is required.

### ⬆️ Dependencies

Metrics now shares Wire 0.10 metadata with Persistence. Tooling's native meter
shares Platform 0.11.1 with Memory. The root lock removes the previous native
Platform 0.9.1 and Wire 0.8/0.9 copies; production retains one provider of each.
The independent native qualification graph also selects Platform 0.11.1 and Wire
0.10. Tooling libraries and CLI generations are adopted together without changing
common catalogs or Shared Tooling. PocketIC remains client/server 16.1.0 and the
qualified stable-structures substrate remains 0.7.2. Earlier tool generations,
failed attempts and historical qualification artifacts remain retained.
