# Persistence 0.62 notes

## [0.62.1] - Unreleased

### ⬆️ Dependencies

Both maintained lockfiles select Wire/Derive 0.14.1 through the existing
compatible requirements. The supplier's update changes native qualification
dependencies; production codec bytes, schemas, budgets and acceptance stay unchanged.
Testkit Native and the independently installed qualification CLI select 0.78.0,
retaining Platform 0.17.0, the owned native client and PocketIC server 16.1.0.
Prepare contributor qualification tools through `make install-runtime-server`.
No persistence API change, data migration or host reset is required.

## [0.62.0] - 2026-11-01

### ⚠️ Breaking

Both maintained catalogs adopt Wire/Derive 0.14.0. `LedgerDecodeError::Wire`
now carries that generation's Rust error identity. Consumers constructing or
matching the payload must align their Wire dependency. The stable adapters make
the matching identity change in their own codec errors. Ledger/checkpoint bytes,
limits, malformed-input admission and allocation custody remain unchanged; no
retained-data transition or reset is required.

The supplier aligns optional Principal/Account schemas with Types 0.16; this
consumer leaves Wire's `platform-types` feature unselected. Metrics 0.24.6 still
requires native-only Wire 0.13 for its default schema support. Preserve that
published requirement and feature behavior, without overrides or duplicate
implementations. Production Wasm and the independent native qualifier each
retain one Wire 0.14 provider. Full native metadata also contains Metrics' Wire
0.13 lane until that supplier adopts the new generation; no native schema-owner
unification is claimed.

### ⬆️ Dependencies

Testkit Native 0.77.0 aligns native measurement helpers with Platform 0.17.0,
removing the dev-only 0.16 provider. Allocation measurement and metered-memory
callers retain their APIs and stable-structures 0.7.2 trait identity. The selected
Testkit CLI 0.76.0 and PocketIC server 16.1.0 are unchanged.
