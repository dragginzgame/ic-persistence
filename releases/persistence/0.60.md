# Persistence 0.60 notes

## [0.60.1] - 2026-10-31

### 🔧 Changed

Shared Tooling’s 0.27.22 commit (`143a9ab`, recorded VERSION 0.27.21) requires a complete root member catalog and group alias
rosters, including unused adapter entries. Each group appears once as a contiguous
dependency block with a separate changelog comment. Repeated lint commentary is
consolidated at its shared scope without changing lint levels. Catalog-only entries add no dependency
edges. Admission checks all local paths, full versions and aliases across groups.
The native release adapter updates selected local requirements on patches as well
as breaking releases, preserving existing operators. Package versions, stored
formats and custody remain unchanged during adoption. Explicit `cargo clean`
removes the owning workspace target, including evidence; retain anything that
must survive separately before requesting cleanup.

## [0.60.0] - 2026-10-31

### ⚠️ Breaking

IC Wire 0.13.0 replaces 0.12.1 in both maintained catalogs. Memory and the stable
adapters expose Wire errors, so hosts exchanging those types must use the same
Wire identity. Ledger and checkpoint bytes, bounds, corruption refusal and custody
are unchanged. Release core suppliers before dependent adapters.

The published Metrics 0.23.2 native metadata feature retains Wire 0.12.1 on
non-Wasm targets. Arithmetic and Serde restoration remain available, and the
production Wasm graph selects only Wire 0.13.0. This adoption does not claim that
Metrics metadata implements Wire 0.13 schema traits. No compatibility wrapper or
feature removal is introduced; schema alignment remains an upstream follow-up.

### ⬆️ Dependencies

Build/Host libraries and the selected metadata editor advance to 0.73.1. Testkit
Native and CLI advance to 0.75.0; Native now shares the selected Platform family,
removing the old native-only Platform 0.13 provider. The PocketIC 16.1.0 pair,
stable-structures 0.7.2, compiler floor and features remain unchanged. Incoming
lockfile updates to Platform/Types and Logging are preserved.
