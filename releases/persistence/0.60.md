# Persistence 0.60 notes

## [0.60.6] - Unreleased

### 🔧 Changed

Native validation/prepared/final receipt readers and retention share Host FS's
bounded regular-file reader and typed JSON admission, with an 8 MiB consumer
ceiling. Missing, oversized and malformed receipts remain failures without reset
or replacement. Captured observations use Host Process's 120-second deadline
with retained output and typed timeout failures. Long-running inherited-IO builds,
full gates and publication commands retain their existing execution policy.

Adopt published Platform 0.16.0 in the library and independent runtime catalogs.
Canonical Types 0.15.1, stable-structures 0.7.2 and PocketIC 16.1.0 are unchanged.
The optional crypto/certification breaks are outside the selected profiles, and
Persistence's public substrate identities and durable bytes remain unchanged.
The native Testkit graph retains its Platform 0.15 dependency; production Wasm
still admits one Platform owner. Incoming unrelated lock selections are preserved.

The composable archive qualification boundary is delivered for review in
[IC Tooling PR #296](https://github.com/dragginzgame/ic-tooling/pull/296).
Persistence retains its current archive qualification until that API is published
and adopted. Repeated grouped validation measured 694.592 seconds across the last
three gates; compiler/configuration identities matched but source/metadata did
not. [Shared #334](https://github.com/dragginzgame/shared-tooling/issues/334) owns
review of input-bound stage-proof reuse; no gate or receipt schema is bypassed.

## [0.60.5] - 2026-11-01

### 🧹 Cleanup

Carry final package evidence with release admission instead of immediately
rechecking it in publication. Effect boundaries still re-admit source, tag,
configuration and archive identities. A single toolchain-derived command plan
supplies execution and receipt expectations without changing receipt JSON.
Metadata projection shares its group observation within a phase and rechecks
policy bytes after helpers. Bootstrap observes each TOML input once and derives
both coherence and scratch edits from that table; release effects still require
the native adapter's real-checkout admission.

Separate pure growth capacity calculations from backing reservation and manager
updates. Fixture diagnostics derive readable/corrupt status from the recovery
observation while preserving report shape, error codes and pre-callback readings.
Release fixtures initialize all group-bearing state together. Correct the current
ownership guide to describe independent groups and archive-map receipts.
No public API, format, allocation custody, retention or publication policy changes.
The suite-wide bootstrap observation proposal is tracked in
[Shared Tooling #333](https://github.com/dragginzgame/shared-tooling/issues/333);
no vendored or sibling source is changed by this local cleanup.

## [0.60.4] - 2026-11-01

### ⬆️ Dependencies

Select published Wire 0.13.2, Build/Host/editor 0.73.3 and Testkit Native/CLI
0.75.2. Both workspace catalogs require the compatible Wire patch; editor and
CLI remain separately installed and checked outside the maintained lockfiles.
Build adds bounded package-command capture with independent retention of both
output logs. Testkit adopts that evidence handling and Host's bounded port-file

Preserve protocol bytes, budgets, native stable-memory helpers and PocketIC's
16.1.0 selection. Keep the existing compiler floor, feature choices and
stable-structures 0.7.2 boundary. No API adaptation, retained-data reset or
migration is required.

## [0.60.3] - 2026-10-31

### 🩹 Fixed

Required native matrix jobs run an explicit classification/documentation admission
step even when a prerequisite fails. A failed prerequisite produces failed required
checks; ordinary full suites and admitted prose reports retain their existing
behavior. Failure collection stays conditional on successful admission. Fixture
checks execute those real admission scripts for success/failure/skipped/cancelled
outcomes. This closes the skipped-check gap in #145 without runtime changes.

## [0.60.0] - 2026-10-31

### ⚠️ Breaking

IC Wire 0.13.0 replaces 0.12.1 in both maintained catalogs. Memory and the stable
adapters expose Wire errors, so hosts exchanging those types must use the same
Wire identity. Ledger and checkpoint bytes, bounds, corruption refusal and custody
are unchanged. Release core suppliers before dependent adapters.

The published Metrics 0.23.2 native metadata feature retains Wire 0.12.1 on
non-Wasm targets. Arithmetic and Serde restoration remain available, and the
production Wasm graph selects only Wire 0.13.0. This adoption does not claim that
Metrics metadata implements Wire 0.13 schema traits. No compatibility wrapper or
feature removal is introduced; schema alignment remains an upstream follow-up.

### ⬆️ Dependencies

Build/Host libraries and the selected metadata editor advance to 0.73.1. Testkit
Native and CLI advance to 0.75.0; Native now shares the selected Platform family,
removing the old native-only Platform 0.13 provider. The PocketIC 16.1.0 pair,
stable-structures 0.7.2, compiler floor and features remain unchanged. Incoming
lockfile updates to Platform/Types and Logging are preserved.
