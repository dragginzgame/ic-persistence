# Persistence 0.61 notes

## [0.61.0] - 2026-11-01

### ⚠️ Breaking

`LedgerCommitError::Codec` carries a public `LedgerDecodeError` instead of a
string. Wire syntax/budget errors, invalid stable keys and invalid manager IDs
remain distinguishable through typed variants and their error sources. Update
code that constructs or inspects the codec payload; display remains diagnostic.
No codec representation, retained-data migration, automatic reset or allocation
custody change is introduced.

Collection lifecycle is explicit across maps, sets, cells, vectors, heaps and
logs: `create` requires empty allocations, `load` never initializes a replacement,
and `reset` deliberately replaces contents under admitted leases. Logs require
both allocations to satisfy the selected lifecycle. Cell writes and retained
loads enforce `T::BOUND`, including exact fixed widths; unbounded records remain
supported through the same cell type. The separate bounded wrapper is removed.

`open_memory` and `memory_id` take a validated `&StableKey`; parse once during
host setup and reuse it. Key syntax is no longer an open-operation error variant.
`MemoryManagerConfig::new` accepts `NonZeroU16` and returns configuration directly;
zero is unrepresentable, while corrupt persisted zero geometry still refuses.
See [the public API migration](../../docs/migration/0.61-public-api.md).
Valid stored collection, ledger and checkpoint bytes remain unchanged; records
violating their declared bounds refuse rather than being automatically reset.

### 🧹 Cleanup

Build 0.73.5 owns qualification of already-produced archives, bounded extraction,
exact extracted-package selection, frozen external locks and final byte/mode
custody. Persistence retains its library checks and native/development-compiler,
native/MSRV and Wasm consumer roster. Consumer fixture source/manifest/lock
custody remains explicit; the superseded Perl renderer and jq graph predicates
are removed. Packaging and release authority remain separate.

Release inspection is carried through adjacent checks without caching across
packaging or remote effects. Each metadata surface receives its role in the
release plan; declared extra manifests stay opaque rather than being rendered
as member version owners. Fixtures derive mechanical manifest/lock inputs from
one roster while independent byte, refusal and recovery assertions remain.
Temporary directories retain exclusive creation, collision refusal and failed
evidence, using one process sequence instead of restarting name scans.

### ⬆️ Dependencies

The release selects Logging 0.23.6 and Metrics 0.24.5 without changing their
features, Wire identity or retained formats. Incoming Build/Host 0.73.5 and
native Testkit 0.76.1 lock selections are preserved; executable pins remain
independent. The installed runtime proof uses the prepared Testkit CLI 0.76.0
and PocketIC 16.1.0 client/server pair.
