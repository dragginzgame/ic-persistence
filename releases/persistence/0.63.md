# Persistence 0.63 notes

## [0.63.0] - 2026-11-02

### ⚠️ Breaking

Memory and Storage now require Rust 1.99.1, matching the workspace's pinned
development/release compiler. The maintainer selected this support contract in
[#151](https://github.com/dragginzgame/ic-persistence/issues/151). Upgrade older
native build environments; no storage migration, host reset or canister data
change is required. Every package inherits its owning workspace floor, including
the independent runtime qualifier. Current package versions remain unchanged
until an explicitly selected release.

### 🧹 Cleanup

Compiler admission compares the root and independent catalogs, member inheritance
and the pin, then records actual Cargo/rustc identities. Different selectors or
compiler observations refuse before archive compilation. Receipt roles retain
their schema but reuse the same rustc observation for the identical support floor.

The native CI matrix retains Linux and both macOS hosts. Its all-target
`test-support` check replaces the distinct proof from the former MSRV matrix.
Default library/archive compilation, strict Clippy, proc macros, Wasm, raw size
budgets and the separate installed-runtime matrix remain. Each extracted library
still compiles independently; the feature-enabled native archive consumer runs
once, followed by its Wasm check. No old compiler cache or historical evidence
is removed. The reviewed Shared snapshot remains unchanged under this explicit
local compiler decision.
