# Metrics Storage 0.67 notes

## [0.67.0]

### ⚠️ Breaking

Public codec errors use Wire 0.16 Rust types; public measurements and numeric
restoration errors use Metrics 0.28. Align direct dependencies when exchanging
these values. Metrics remains the arithmetic and validated Serde owner and no
longer depends on Wire or supplies native metadata.
Consumers must own frontend/report DTO schemas instead of relying on this adapter
to enable foreign Metrics Wire implementations. No replacement schema surface or
integration crate is added.

The obsolete direct Metrics schema test is removed under [Storage #154 — Remove Metrics-native schema coupling](https://github.com/dragginzgame/ic-storage/issues/154)
and [Observability #128 — Remove Metrics Wire metadata dependency](https://github.com/dragginzgame/ic-observability/issues/128).
Frozen `ICMW` rows, field order, constructor validation, exact-cap/overflow semantics,
continuity and reopen coverage remain. No reset or retained-data migration is needed.
Native production graph admission refuses accidental Metrics `native-wire` feature
unification and requires one Wire identity. This adoption uses published Metrics
0.28.0 with the supplier metadata removal complete.
