# Metrics Storage 0.67 notes

## [0.67.0]

### ⚠️ Breaking

The adapter no longer enables Metrics’ optional `native-wire` feature or promises
Wire implementations for Metrics types. Services own frontend/report DTO schemas;
Storage keeps its own stored codec and Metrics remains the validated Serde and
arithmetic owner. No foreign trait implementations or integration crate replace
the removed schema-only test.

Frozen `ICMW` rows, field order, numeric validation, exact-cap/overflow semantics,
continuity and reopening remain unchanged. No reset or data migration is needed.
Native production admission requires one Wire identity and refuses accidental
Metrics metadata feature unification.

This prepares the local portion of [Storage #154](https://github.com/dragginzgame/ic-storage/issues/154)
against published Metrics 0.27, independently of supplier removal in
[Observability #128](https://github.com/dragginzgame/ic-observability/issues/128).
Qualification with that future supplier remains a separate acceptance step.
