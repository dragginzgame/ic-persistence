# Metrics Storage 0.70 notes

## [0.70.0] - Unreleased

### ⚠️ Breaking

Adopt Storage 0.68's governed collection and runtime type identities. Hosts
passing Storage handles or errors across this boundary must align their Storage
dependency; the adapter still owns validated IC Wire metric snapshots.

The underlying collection format changes with Storage's copied-ICSS hard cut.
Existing collection images require explicit host rebuild/reset or fresh admitted
allocations. There is no legacy reader, automatic reset or implicit conversion.
Metric snapshot payload bytes and metric restoration semantics are unchanged.
See [Storage's migration requirements](../storage/0.68.md).
