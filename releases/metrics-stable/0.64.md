# Metrics Stable 0.64 notes

## [0.64.0] - Unreleased

### ⚠️ Breaking

The adapter now requires Metrics 0.25.0. Public checkpoint/load methods exchange
that generation's measurement values, and numeric restoration errors likewise
carry its Rust identity. Hosts must align direct Metrics dependencies to 0.25
before exchanging these types; unchanged arithmetic method signatures do not
make Metrics 0.24 values interchangeable with Metrics 0.25 values.

Native metric metadata now uses the same Wire 0.14 trait identity as the adapter.
The old Wire/Derive 0.13 packages leave the root lock without feature suppression,
dependency overrides or conversion wrappers. Existing default features remain
selected. The independent runtime qualifier is unaffected by this adoption.

The subsequent refresh selects Wire/Derive 0.14.1 in both maintained lockfiles.
Its native qualification update preserves the Wire 0.14 Rust identity, numeric
metadata, encoded rows, limits and acceptance behavior. Testkit Native and the
qualification CLI select 0.78.0 with the same server 16.1.0 pin.

Numeric shapes, Serde admission, arithmetic, stored metric rows, record bounds
and checkpoint continuity remain unchanged. Frozen records reopen without
reencoding; no retained-data transition or reset is required. Memory/Storage and
Logging Stable release identities remain unchanged.
