# Storage 0.67 notes

## [0.67.1] - Unreleased

### 🔧 Tooling

Adopt Shared Tooling 0.30.0 at `b37a882`, including readable workspace LOC
labels and complete exported documentation links. Classify fixtures, benchmarks and
release tooling by their maintained directory roles. Share passive qualification
protocols through one private fixture crate instead of cross-directory source
inclusion. Remove broad lint allowances, fix actionable warnings, and scope
remaining expectations to the configurations that emit them. Document public
error contracts and escape captured native diagnostic controls.

Public APIs, wire bytes and persistent layouts are unchanged. Release commands
and the three published package identities remain unchanged.

## [0.67.0] - 2026-11-04

### ⚠️ Breaking

Adopt published IC Wire 0.17.0 through the workspace catalog. StorageConfig::wire and Storage codec errors
use the new Wire crate identity. Hosts constructing or matching these public
values must align their IC Wire dependency; this requires the next minor release.

Wire 0.17 makes metadata derivation optional. This package uses the codec-only
path, without `typescript`, `platform-types` or endpoint macros. No replacement
serialization layer, compatibility decoder or migration is introduced. Codec
bytes, resource budgets and persisted layouts remain unchanged, so no backing
reset is required. Both workspaces remove `ic-wire-derive` from their selected
locks. No other supplier versions are updated by this adoption.

admission and installed IO/upgrade/rollback qualification pass. Formatting and
dependency pins pass. Evidence: `target/wire-017-adoption/`; installed attempt
`mM9Pm5`. Release qualification additionally runs the complete Storage group gate.
