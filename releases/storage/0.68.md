# Storage 0.68 notes

## [0.68.0] - Unreleased

### ⚠️ Breaking

Replace all collection engines with private copied ICSS 0.7.2 source: B-tree,
Set over that B-tree, fixed-stride Vector, cached Cell and governed map regions.
Keep Storage's allocation directory, custody checks, existing application codecs
and successful-call API shapes. There is no production ICSS dependency or ICSS
MemoryManager. [Provenance and adaptations](../../docs/storage/upstreams.md).

Every prior Storage collection image requires an explicit host rebuild/reset or
fresh admitted allocation. Current framing is BTR2 (explicit page size), SVC1 and
SCL1. Hosts must update collection/region framing admission. No legacy reader,
implicit conversion or automatic reset exists. Directory encoding is unchanged.

Inside collections, malformed codecs, engine state and allocation failures now
trap, including operations whose successful-call API still returns Result.
Explicit framing admission and page reservation retain typed failures. Native
mutation panics may leave partial bytes and poison the shared owner; discard its
runtime and leases. IC execution rollback remains the Wasm atomicity mechanism.
There are no collection checksums; application validation cannot detect every
valid-looking byte change. Cell retains its caller-selected load ceiling.

### 🔧 Changed

Delete the prior independent tree/block allocator, record envelopes, node cache,
Vector scan windows, cached length and mutation epochs. Preserve one algorithm
implementation behind the public governed adapter layer. `set_node_cache_budget`
remains a ceiling hint satisfied by the baseline's zero cached bytes, not a cache
enabler. New benchmark runs reject positive Storage cache budgets.

Storage primitive codecs are unchanged. In particular, unsigned encodings differ
from ICSS's default codecs; exchanging images requires matching application
codecs and bounds. Six same-image tests explicitly match those codecs and
exchange updates with separately published ICSS across all supported forms.

The earlier checksum-free ICVEC002 experiment and its measurements remain
historical controls. They do not measure this baseline or establish its speed.

### 🧪 Testing

Generate the complete ICSS/Storage type union across Map, Set, Vector, Cell and
map regions, including the full ICSS B-tree type grid. Keep typed dispatch and
independent field/state validation; record per-backend incompatibilities instead
of hiding them or inventing ratios. Automatic collection shards, correct CSV
quoting and gzip installation transport keep the large synthetic matrix usable.
[Coverage contract](../../docs/audits/recurring/benchmark-full-catalogue-2026-11-05.md).

Qualify 46,604 installed measured calls and final states over 565 cases / 73
types, plus 42 focused native tests. Verify all 53 expected runtime refusals and
record non-Ord roles explicitly. Retain selected per-case results and compact
identities; full per-run output stays in target evidence. The largest inline-key synthetic handler uses a common eight-MiB
benchmark stack; production stack settings are unchanged.

The catalogue supersedes the earlier 58-case `types` selection and includes all
nine key/value bound combinations, variable binary/composite keys, zero-sized
and scalar values, optional records and Vector prefix thresholds. The current
preset uses 32 rows, capped for finite key domains. Shared codecs and actual
native ICSS optional-codec refusals are explicit; production codecs are unchanged.

Add independent-model collection histories and same-image published-ICSS checks,
including split/overflow/removal, all supported collection forms and governed
regions. Native IO regressions bound populated Vector lookups and protect direct
iterator skipping/count without decoding discarded records. Original final Wasm
passes installed IO/upgrade/rollback qualification across 1,031 allocations.

Record a fresh complete 3,196-call comparison, 824 affected iterator reruns and
480 Auth-shaped query/update calls. First-record 2 KiB Get at 2,048 rows costs
88,435 vs ICSS 86,094 instructions; the pre-read variant is 8,435 vs 6,094.
These measure configured stacks and do not establish a universal speedup.
[Final baseline and limitations](../../docs/audits/recurring/icss-engine-baseline-2026-11-05.md).

### 🔧 Tooling

Adopt Shared Tooling 0.30.5 with lexical Candid checks across packages, helper,
benchmarks and runtime fixtures, plus direct CBOR dependency exclusions in both
workspaces. Select the refreshed LOC/formatting scratch defaults and release
changelog handling. New raw comparisons use `target/evidence/`.

Consolidate experimental reports and retire bulk exports and obsolete prototype
patches. Keep current coverage, selected absolute results and reproduction
details within Shared's evidence budgets. Current code, release/recovery records,
tool caches and existing target run directories are unchanged by this cleanup.

Add an isolated stable-read diagnostic over frozen original Vector images, with
neighbouring-index and combined-read controls. Validate returned bytes against
the actual stable image and distinguish source-granule bypass from native region
charging. Document that an untimed pre-read can move charges across the timing
boundary; it is not a conventional warm-cache measurement.

Add a named iterator benchmark preset covering seven Vector types, eleven lengths
and thirteen operations, with independent result and persisted-state checking.
Direct skipping, alternating ends and writes during iteration join the ordinary
Vector matrix. Separate wide-value selections keep the default preset bounded;
its one-sample default retains three stateful rounds. See the
[benchmark guide](../../testing/runtime-qualification/crates/ic-storage-benchmarks/README.md#iterator-coverage).

Add an `ordered` Map/Set preset with shuffled population, nine batch lengths,
key-only/value-only ranges, direct skipping and mixed-end Map traversal. Extend
ordinary ordered cases too. Missing-removal keys are now disjoint from inserted
keys at every admitted batch size; the independent model caught the former
fixed-offset overlap at 128 items. Paired Set timings use its actual ICSS API,
without emulating unavailable reverse iterators.

Add a population-scaled session-envelope lookup preset for the Canic/Auth
performance investigation, separating Vector Get, prewarmed Get and outer Wire
decoding in query/update executions. A native regression bounds backing IO and
decode counts after reopening. The matched 480-call study does not reproduce the
reported population-dependent cost jump; it does not qualify Canic configuration
preparation or Auth's inner session decoder. See the
[scope and results](../../docs/audits/recurring/icss-engine-baseline-2026-11-05.md).
