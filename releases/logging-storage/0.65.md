# Logging Storage 0.65 notes

## [0.65.0] - Unreleased

### ⚠️ Breaking

Adopt published IC Wire 0.17.0 through the workspace catalog. Logging checkpoint codec errors
use the new Wire crate identity. Hosts constructing or matching these public
values must align their IC Wire dependency; this requires the next minor release.
Package versions remain at their published values until a release is requested.

Wire 0.17 makes metadata derivation optional. This package uses the codec-only
path, without `typescript`, `platform-types` or endpoint macros. No replacement
serialization layer, compatibility decoder or migration is introduced. Codec
bytes, resource budgets and persisted layouts remain unchanged, so no backing
reset is required. Both workspaces remove `ic-wire-derive` from their selected
locks. No other supplier versions are updated by this adoption.

admission and installed IO/upgrade/rollback qualification pass. Formatting and
dependency pins pass. Evidence: `target/wire-017-adoption/`; installed attempt
`mM9Pm5`. No release or registry publication is performed by this adoption.
